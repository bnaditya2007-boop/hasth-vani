# Hasth Vani - images

Visual assets for docs, presentations, or a project README.

```
images/
├── diagrams/                 PNG renders of the 24 SVGs in hardware/diagrams/
└── 3d_model_screenshots/     Screenshots of the interactive 3D wiring model
```

`3d_model_screenshots/` contents:

- `full_circuit_all_wired.png` - the complete left-glove circuit, everything wired
- `battery_wiring_isolated.png` - just the battery pack's two wires highlighted, rest dimmed
- `thumb_sensor_isolated.png` - just the thumb flex sensor's wiring highlighted
- `tft_display_test_final.png` - the TFT-only test build, fully wired
- `battery_only_model.png` - the standalone battery-power wiring model

**No real photos of the physical build are in here yet** - everything
above is a rendered diagram or a 3D model screenshot, not a photo of the
actual gloves/breadboards. Add real photos here as the build progresses
(e.g. `photos/left_glove_breadboard.jpg`, `photos/thumb_sensor_closeup.jpg`)
once you have them; they're the most useful thing for actually debugging
wiring issues like the current blank TFT screen and the low thumb reading.
